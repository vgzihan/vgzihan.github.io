FLOWBOARD — SINGLE HTML FILE

The whole website is inside index.html. CSS and JavaScript are embedded in the file; there are no separate HTML pages or CSS files to link.

To use on your phone: extract this folder and open index.html. Use the navigation links and Start button to switch between Home, Dashboard, About, and Privacy Policy.

For GitHub Pages: upload index.html (README.txt is optional) to the root of your repository, then enable GitHub Pages from Settings > Pages.

Note: some Android file viewers restrict JavaScript or local storage for files opened directly. If the dashboard does not save tasks in a local file preview, publish index.html with GitHub Pages and open the published website in your browser.
